Skill configuration:

- **Trigger:** "When a scenario is called". The skill can be started directly by a user, and Joule generates the
  response from the action output.
- **Inputs:** `caseNumber`, `assemblyCode` and `caseStatus`, all optional strings. `caseNumber` was added today; its
  description gives the format "EC- plus six digits, e.g. EC-000485".
- **Action step:** *Look up cases* calls `LookupEngineeringCases` (`GET /lookupCases`, read-only) with all three
  inputs mapped, through the destination variable `assemblyImpactBackend`.
- **Branches:**
  - Success 2XX: Joule generates the answer.
  - Default (any error, including 404 for a missing case or another plant): *Send Message 1*.

Not configured in the skill yet: the impact, findings and decision-history steps (`GetEngineeringImpact`,
`GetDecisionHistory`). These are specified in `skills.json` but would only be configured once the destination below
exists, because each step needs it to be tested.

## Blocked (exact operations)

1. **Test.** The *Test* dialog needs an **Environment**, and the list is empty. The destination variable
   `assemblyImpactBackend` can only be mapped to destinations that already exist in the shared EU10 subaccount. None
   of them points to the AssemblyImpact backend. They belong to other tenant users and were not used.
2. **Destination.** Joule needs a destination to the deployed CAP service (US10:
   `78485bd6trial-dev-assemblyimpact-srv…`) with principal propagation (`OAuth2JWTBearer`, see
   `destination.template.json`). That requires trust between the EU10 subaccount and the US10 XSUAA
   (`assemblyimpact-auth`). Creating it is a subaccount administration task in a shared tenant. It is outside my
   permissions and outside "do not modify others' shared resources".
3. **Release and agent.** The skill was not released, because the directive requires a successful test before
   release, and testing is blocked by 1 and 2. A released Actions project does **not** mean the skill is deployed.

The status of P1 is therefore *completed as a design-time artifact (skill saved and validated), blocked for runtime
by the EU10 destination/environment*. Joule Studio classic shows a notice that its generative AI features are
deprecated from January 2027.
